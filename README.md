Banco de Dados — Sistema de Adoção de Animais

Sobre o projeto

Este projeto consiste no desenvolvimento de um banco de dados relacional para um sistema de adoção de animais, desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS).
O objetivo é organizar as informações dos usuários, das organizações não governamentais (ONGs), dos animais disponíveis para adoção e dos pedidos de adoção.

Tecnologias utilizadas

MySQL
MySQL Workbench
GitHub

Estrutura do banco de dados

O banco de dados é composto pelas seguintes tabelas:
usuario: armazena as informações dos usuários cadastrados no sistema.
ong: armazena as informações das organizações responsáveis pelos animais.
animais: registra os animais cadastrados para adoção.
tags: organiza etiquetas associadas aos animais.
pedido: registra os pedidos de adoção realizados pelos usuários.
mensagens: armazena as mensagens trocadas no sistema.

Arquivo do projeto

banco_de_dados.sql: arquivo SQL exportado pelo MySQL Workbench, utilizado para recriar a estrutura do banco de dados e recuperar os dados incluídos na exportação.# projeto-banco-de-dados

Finalidade acadêmica

Este projeto tem como finalidade aplicar conhecimentos de modelagem de dados, criação de tabelas, definição de chaves primárias e estrangeiras e organização de bancos de dados relacionais.
Os dados utilizados para testes devem ser fictícios e destinados exclusivamente a fins acadêmicos.
